1.7 October 25, 2026
DMG

Graphite, and ready for Xcode 27.

New

  • Graphite, a new dark design for the panel and the Network Monitor.
  • Request list: query filters (status:>=400 host:api slow:>300ms), p50/p95 in the status bar, and Copy as cURL, fetch, HTTPie or Swift.
  • Auth tab: decodes JWTs, shows when the token expires and which requests use it. Copied requests hide secrets.
  • Generate Model: turns a JSON response into Swift Codable types.
  • Location: paste coordinates or a Maps link, and play GPX routes at walking, biking or driving speed.
  • Debug tab: Shake (⌃⌥⌘Z) and Memory Warning, which Xcode 27's Device Hub no longer offers.
  • Window mode: the panel's tabs in a regular window.

Fixed

  • Xcode 27 and iOS 27: Device Hub is recognized, memory warnings reach apps again, and screenshots and recordings save correctly.
  • Apply & Relaunch now relaunches the app in the new language and time zone.
  • Location permission, UserDefaults loading, contract drift and the deep link app lookup work again.
  • The Mocked badge no longer wraps, and the request lists are tidier.
  • Many smaller fixes across the panel.
1.6 August 16, 2026
App StoreDMG

Four new tools for your network workflow.

New

  • Contracts: save the shape of an API response and get warned the moment that endpoint starts returning something different.
  • Edit & Resend: right-click a captured request to change its method, URL, headers or body, send it again, and compare the responses side by side.
  • Load Tests: fire a burst of concurrent requests at an endpoint and watch success rate, latency percentiles and status codes build up live.
  • WebView Requests: page loads inside embedded web views now appear in the request list with their own badge. Requires SimKit SDK 1.6.0.
