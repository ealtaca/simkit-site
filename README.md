# simkit.dev

The SimKit website, served by GitHub Pages at https://simkit.dev.

Releases (the DMG) and the Sparkle appcast live in
[ealtaca/simkit-website](https://github.com/ealtaca/simkit-website), whose GitHub Pages
address (`ealtaca.github.io/simkit-website/appcast.xml`) installed apps check for updates.
That site must keep no custom domain: GitHub would redirect it to `http://`, which apps refuse.
