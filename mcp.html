Why

An agent can read your code. It can't see your app run.

It doesn't know which request went out, what came back, or what happens on a 401 or a slow connection, so it guesses. SimKit already watches all of that beside your simulator. MCP hands it to the agent.

  • List the requests my app made in the last minute and tell me which ones failed.
  • Throttle the network to 3G and tell me which requests get slow.
  • Switch the simulator to dark mode with the largest text size and show me the screen.
  • Expire my auth token and check that the app refreshes it once, not five times.
  • Create a bug report for my app.

Setup

Three steps.

  1. Get SimKit

    The MCP server is part of the Mac app, in version 1.8 or later. Download SimKit, free, from the Mac App Store or as a DMG.

  2. Turn on Coding Agents

    Open SimKit's panel, go to the Agents tab and switch it on. It is off until you do.

  3. Connect your agent

    Press Install next to your agent in the Agents tab, or add SimKit yourself:

    Claude Code

    Terminal
    claude mcp add simkit -- npx -y simkit-mcp

    Cursor, Kiro and other clients

    mcp.json
    {
  "mcpServers": {
    "simkit": { "command": "npx", "args": ["-y", "simkit-mcp"] }
  }
}

    Codex

    ~/.codex/config.toml
    [mcp_servers.simkit]
command = "npx"
args = ["-y", "simkit-mcp"]
Privacy

It stays on your Mac.

  • Local only. The server listens on 127.0.0.1 and turns away anything that isn't on your Mac.
  • Off by default, behind a token. Nothing can connect until you turn it on, and only with the token SimKit made for you.
  • Reads are marked as reads. Every tool says whether it changes anything, so your agent can ask before it resets an app and not before it lists requests.
  • Nothing is uploaded by SimKit. What your agent reads, it sends to its own model provider, as with any file it reads.
FAQ

Questions, answered.

Is it free?

Yes. SimKit and its MCP server are free, with no account.

Which coding agents does it work with?

Any MCP client. SimKit sets up Claude Code, Cursor, Codex and Kiro for you from the Agents tab, and simkit-mcp works with any client that runs a command.

Do I need the SimKit SDK?

For the simulator tools, no. Network capture, mocks and throttling need the one-line SimKit SDK in your debug build, or the DMG build of SimKit.

Can the agent tap and type in my app?

No. SimKit observes and sets things up: requests, mocks, app data, simulator settings and screenshots. Use it next to the tool you already build and tap with.

Does my app's data leave my Mac?

Not through SimKit. Headers and bodies reach your agent as the app sent them, tokens included, so treat them as you would any secret your agent can read. Tools that return them take a redact option.

It says SimKit isn't reachable.

Open SimKit and check that Coding Agents is on in the Agents tab. The agent connects to the app, so the app has to be running.
